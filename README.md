# Školski IT klub / Coding Club

Prezentacijska web stranica školskog kluba za programiranje i tehnologiju.
Projektni zadatak iz predmeta Softversko inženjerstvo (4. razred, IT smjer).

## Sadržaj stranice
- Početna (hero sekcija i dugme za prijavu)
- O nama
- Članovi
- Projekti (kartice)
- Kontakt / Prijava (forma s JavaScript validacijom)
- Responzivan dizajn (mobitel i računalo)

## Struktura projekta
index.html
style.css
script.js
docs/ (wireframe, mockup i izvještaj)
README.md

## Pokretanje
Preuzmi projekat i otvori `index.html` u pregledniku.
Fajlovi `index.html`, `style.css` i `script.js` moraju biti u istom folderu.

## Tehnologije
HTML5, CSS3, JavaScript, Git i GitHub.
